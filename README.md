# Urban Keys FL26 (VST3, Windows x64)

Piano urbano tipo Coculuela con 12 presets. Sintetizador VST3 para FL Studio.

## Compilar sin instalar nada (GitHub Actions)
1. Crea un repositorio publico en github.com.
2. Sube TODO el contenido de esta carpeta (incluida la carpeta oculta `.github`).
3. Pestana **Actions** -> espera la palomita verde (10-20 min).
4. Abre la ejecucion -> **Artifacts** -> descarga `UrbanKeysFL26-VST3-Windows-x64`.

## Instalar
Descomprime y haz clic derecho en `Instalar.bat` -> **Ejecutar como administrador**.
(Copia el plugin a `C:\Program Files\Common Files\VST3`.)

En FL Studio: Options -> Manage plugins -> Find installed plugins.
Aparece en Plugin database -> Installed -> Generators como "Urban Keys FL26".
